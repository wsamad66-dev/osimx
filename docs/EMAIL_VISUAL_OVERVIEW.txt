    ÉTAPE 1: Créer un compte Resend
    ├─ Aller sur: https://resend.com/signup
    ├─ Inscription gratuite (GitHub/Google)
    └─ Plan gratuit: 100 emails/jour ✅

    ÉTAPE 2: Obtenir la clé API
    ├─ Dashboard → API Keys
    ├─ "Add API Token"
    └─ Copier la clé (re_abc123...)

    ÉTAPE 3: Configurer l'environnement
    ├─ Ouvrir .env.local
    ├─ Ajouter: RESEND_API_KEY=re_votre_cle
    └─ Sauvegarder

    ÉTAPE 4: Installer le package
    └─ npm install resend

    ÉTAPE 5: Activer le code
    ├─ Ouvrir: src/app/api/send-email/route.ts
    ├─ Ligne 3: Décommenter import { Resend }
    ├─ Ligne 5: Décommenter const resend = new Resend(...)
    └─ Lignes 32-50: Décommenter tout le bloc Resend

    ÉTAPE 6: Tester
    ├─ Inscrire un étudiant test
    ├─ Vérifier votre boîte email
    └─ Vérifier le dashboard Resend

    ✅ C'EST TOUT ! Les emails sont envoyés automatiquement.
