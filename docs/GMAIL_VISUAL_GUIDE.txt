    ┌─────────────────────────────────────────────────────────────────┐
    │ ÉTAPE 1: MOT DE PASSE D'APPLICATION GMAIL (2 minutes)          │
    └─────────────────────────────────────────────────────────────────┘
    
    1. Ouvrir: https://myaccount.google.com/security
       
    2. Activer "Validation en deux étapes"
       ├─ Si déjà activée: ✅ Passez à l'étape suivante
       └─ Si pas activée: Cliquez et suivez les instructions
    
    3. Cliquer sur "Mots de passe d'application"
       ├─ Application: Mail
       ├─ Appareil: Autre (appareil personnalisé)
       └─ Nom: "L'Étudiant Étranger"
    
    4. Cliquer "Générer"
    
    5. Copier le mot de passe de 16 caractères
       ├─ Format: abcd efgh ijkl mnop
       └─ ⚠️ Vous ne le verrez qu'une seule fois!


    ┌─────────────────────────────────────────────────────────────────┐
    │ ÉTAPE 2: CONFIGURATION .env.local (1 minute)                    │
    └─────────────────────────────────────────────────────────────────┘
    
    Ouvrir: /Users/asf/Documents/GitHub/osimx/.env.local
    
    Remplacer ces lignes:
    
    ┌───────────────────────────────────────────────────────────────┐
    │ GMAIL_USER=your-email@gmail.com                               │
    │ GMAIL_APP_PASSWORD=your-16-char-app-password                  │
    │ TEAM_EMAIL=contact@letudiantetranger.com                      │
    └───────────────────────────────────────────────────────────────┘
    
    Par VOS valeurs (exemple):
    
    ┌───────────────────────────────────────────────────────────────┐
    │ GMAIL_USER=ouassim.samad@gmail.com                            │
    │ GMAIL_APP_PASSWORD=abcdefghijklmnop                           │
    │ TEAM_EMAIL=contact@letudiantetranger.com                      │
    └───────────────────────────────────────────────────────────────┘
    
    💡 Conseil: Utilisez un email dédié si possible
               (ex: noreply@letudiantetranger.com avec Gmail)


    ┌─────────────────────────────────────────────────────────────────┐
    │ ÉTAPE 3: RELANCER LE SERVEUR (30 secondes)                      │
    └─────────────────────────────────────────────────────────────────┘
    
    Terminal:
    
    # Arrêter le serveur (Ctrl+C)
    
    # Relancer
    npm run dev
    
    # Attendre "Ready in Xms"
    
    ✅ C'est tout ! Le système est prêt.

    ❌ ERREUR: "Invalid login"
    
    CAUSE: Mot de passe d'application incorrect ou manquant
    
    SOLUTION:
    1. Vérifier que la validation en 2 étapes est activée
    2. Créer un NOUVEAU mot de passe d'application
    3. Copier les 16 caractères SANS espaces
    4. Mettre à jour .env.local
    5. Relancer le serveur
    
    ──────────────────────────────────────────────────────────────────
    
    ❌ ERREUR: "Username and Password not accepted"
    
    CAUSE: Vous utilisez votre mot de passe Gmail normal
    
    SOLUTION:
    Utilisez le MOT DE PASSE D'APPLICATION (16 caractères)
    PAS votre mot de passe Gmail habituel !
    
    ──────────────────────────────────────────────────────────────────
    
    ❌ Emails non reçus
    
    VÉRIFICATIONS:
    1. ✅ Console montre "✅ Email envoyé" ?
    2. ✅ Vérifier le dossier SPAM dans Gmail
    3. ✅ Vérifier l'adresse email du destinataire
    4. ✅ Vérifier les "Messages envoyés" dans Gmail
    
    ──────────────────────────────────────────────────────────────────
    
    ❌ ERREUR: "Daily sending quota exceeded"
    
    CAUSE: Plus de 500 emails envoyés aujourd'hui
    
    SOLUTIONS:
    - Attendre 24 heures (quota se réinitialise)
    - Utiliser un autre compte Gmail
    - Passer à Google Workspace ($6/mois = 2000/jour)
    - Passer à Resend ou SendGrid
