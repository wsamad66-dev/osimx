## ⌨️ Keyboard Navigation Map

```
Tab Order:
1. Hero CTA buttons
2. Stats section (not interactive)
3. Country selector cards (France → Canada → Belgique → Italie → Chine)
4. Selected country CTA
5. Testimonials controls (Prev → Dots → Next → Play/Pause)
6. Floating CTA
7. WhatsApp button

Shortcuts:
- Tab: Move forward
- Shift+Tab: Move backward
- Enter/Space: Activate button
- Escape: Close floating CTA
- Arrow keys: Navigate carousel (optional enhancement)
```
