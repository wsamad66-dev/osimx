## 🎬 Animations Flow

### Page Load Sequence
```
t=0s     Navigation appears      ─────────────────────────────────▶
t=0.2s   Hero left fades up      ────────────▶
t=0.4s   Hero right slides in              ────────────▶
t=1.0s   Badge 1 pops                                  ───▶
t=1.2s   Badge 2 pops                                      ───▶

Scroll ▼

t=0s     Section badge appears   ─────▶
t=0.1s   Title fades up                 ────▶
t=0.2s   Subtitle fades up                   ────▶
t=0.3s   Card 1 fades up                         ────▶
t=0.4s   Card 2 fades up                              ────▶
t=0.5s   Card 3 fades up                                   ────▶
```

### Hover Effects
```
Card Hover:
┌──────────┐              ┌──────────┐
│  Card    │  ──hover──▶  │  Card    │  ↑ -8px
│          │              │  [glow]  │  scale 1.02
└──────────┘              └──────────┘
```

### Carousel
```
Testimonial 1  ◀────6s────▶  Testimonial 2  ◀────6s────▶  Testimonial 3
     ●                            ○                            ○
Auto-play avec slide transition (x: 50 → 0 → -50)
```
